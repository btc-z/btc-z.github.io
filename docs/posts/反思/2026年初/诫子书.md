# 诫子书

!!! quote
    夫君子之行，静以修身，俭以养德。

    非淡泊无以明志，非宁静无以致远。

    夫学须静也，才须学也，非学无以广才，非志无以成学。

    淫慢则不能励精，险躁则不能治性。

    年与时驰，意与日去，遂成枯落，
    多不接世，悲守穷庐，将复何及！


友人送字，又刚好卡在大雪天，便左思右想了诸葛亮的这86个字。

【静】字用了三次，几乎为首，第一静为动词，让心安静下来才能修养身心。不静则会被噪音左右，而噪音会伤心神和体魄。俭字即是物质的节俭，也是内心的节俭，【俭】是去掉噪音，去掉不需要对生活没有意义徒增烦恼徒增欲望的事和人，进而去【养】德。读到这里，停顿了下，哦！原来道德是被养起来的。养字用的妙。原来诸葛亮用词很主动哎。人生的轨迹在自己的手里。自己去修身，自己去养德。自己去行君子路。


淡泊名利何其难。众生又有何人不是为了讨口饭吃，所以不是祛除名利，而是淡泊名利，这是心法，把【名】和【利】看淡。工作也好，创业也罢，不过度图名，不只为赚钱。在不是为了名声和金钱的前提下，是什么在激励我们前进？那东西便是【志】。“非志无以成学”，没有志向，成不了学问，因为没有那最强大的，最原始的动力。“非学无以广才”，妙在【广】字。书读多了，理自然大了。以理服人，即能驱使群众，也可驾驭自身。没有志，无法成就大的学问，没有大的学问，自然没有大的道理，也不能服众，更不能服自己，进而无法成为真正的人才。

【淡泊】名利，给了方向；【宁静】，不分散精力，不被噪音干扰，则可以走的更远，更深刻。志是方向，静则决定了长远深浅。两者合在一起，变成了一个矢量、变成了生命力、创造力、驱动力和业力。

放纵懒惰会让精神萎靡，轻薄浮躁则无法培养品性。前者是在鼓励自律，勤奋；后者是在劝诫不去冒大险，不浮躁进而有耐心，去培养自己的心性。

他刻画出的是一个：自律、勤奋、扎实、有耐心、极为专注，时刻规避噪音的人格。在诸葛亮眼里，这样的人，即是他自己，也是他希望后代可以成为的人，无论是样的志向。
